## 100 экспертных Telegram-каналов о маркетинге (сентябрь 2026)

Подборка из 100 русскоязычных экспертных Telegram-каналов о маркетинге с оценкой
по 7 критериям (экспертиза, практичность, уникальность, регулярность, влияние,
чистота от рекламы, подача) — для приоритизации чтения, выжимки и поиска инсайтов.

| Файл | Что это |
| --- | --- |
| `marketing-channels-100.md` | Главный отчёт: критерии, сводный рейтинг, 13 разделов, методика выжимки и поиска инсайтов, источники |
| `marketing-channels-100.csv` | Полная таблица (Excel/Google Sheets): баллы по каждому критерию, итог, уровень |
| `build_report.py` | Скрипт-генератор: правьте данные/оценки и запускайте `python3 build_report.py` |
